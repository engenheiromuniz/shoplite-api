# ShopLite API

E-commerce simplificado desenvolvido com Spring Boot, como projeto de estudo
aprofundado em Testes (JUnit 5, Mockito, TDD), JPA, Spring Security e
Padrões de Projeto.

## Em construção 🚧
Este projeto está sendo desenvolvido de forma incremental e documentada.

## Tecnologias
- Java 17+
- Spring Boot
- Spring Data JPA
- Spring Security
- JUnit 5 + Mockito
- Maven
